## 1. 为什么改：Phase 0 的三个字段是继承来的，没搜过

旧的三个头（EBIT/净资产、营收增长、OCF/净资产）来自 LFM 的字段口味 + "三个头不冗余"。
`phase0_label_anchor_experiment.md` 只在 `{ebit, revenue, ocf}` **三个字段之内**比过分母锚，
**从没在字段空间里搜过**。

## 2. 决定性发现：朴素持续性基准碾压所有价格因子

基准 =「上一轮重演」（锚点日即可算出、**完全不用价格信息**）。h=3 的结果（SHZ+SHH，75 个锚点）：

| 标签 | 价格因子 IC | **朴素基准 IC** | 增量 IC（残差） | 增量 ICIR |
|---|---|---|---|---|
| Δ净资产/净资产 | +0.342 | **+0.783** | +0.279 | +4.31 |
| 留存收益/总资产 | +0.337 | **+0.800** | +0.272 | +4.18 |
| Δ总资产/总资产 | +0.311 | **+0.779** | +0.252 | +3.61 |
| 营收/总资产 | +0.200 | **+0.828** | +0.226 | +4.00 |
| 毛利/总资产 | +0.287 | **+0.761** | +0.197 | +3.40 |
| EBIT/总资产 | +0.299 | **+0.547** | +0.118 | +2.11 |
| EBIT/净资产（旧） | +0.280 | **+0.525** | +0.116 | +2.12 |
| **OCF/总资产** | −0.123 | **+0.303** | **−0.045** | **−1.12** |
| OCF/净资产（旧） | −0.114 | +0.280 | −0.043 | −1.17 |

**没有任何一个字段，价格因子在原始 IC 上打得过"什么都不做、假设上一轮重演"。**
扣掉持续性后的**增量** IC 仍有 0.12~0.28（ICIR 2~4）——方向没死，但比之前以为的小一个量级。

→ **之前所有"IC/ICIR 很漂亮"的数字主要是持续性，不是 nowcast 能力。** 所以评估必须同口径比基准。

## 3. 定案：三个输出头

| 头 | 定义 | 经济含义 | 增量 IC |
|---|---|---|---|
| `grossProfit` | `Σ grossProfit[j+1..j+h] / totalAssets[j]` | 前瞻毛利率（盈利性） | 0.197 |
| `revenueGrowth` | `Σ revenue[j+1..j+h] / Σ revenue[j-h+1..j]` | 前瞻营收增长（规模） | 0.216 |
| `assetGrowth` | `totalAssets[j+h] / totalAssets[j]` | 前瞻资产增长（投资） | 0.252 |

**换掉了 OCF**：增量 IC 只有 −0.045（≈0）且与持续性符号相反，同时分母 ≤0 造成 29.9% 覆盖损失。
它是三个头里唯一"价格里没有增量信息"的。

分母统一用**总资产**（恒正 → 不再有分母 ≤0 丢样本的问题），取代 Phase 0 建议的"统一用净资产"。

## 4. 为什么头 1 用毛利而不是 EBIT

原本的用法是 **EBIT/EV 估值排序**（LFM 路线）。但：

1. **毛利也能做估值**：`预测毛利 = 预测(毛利/总资产) × 总资产[j]`，再除以当前**市值**得 `毛利/市值`。
   市值恒正、毛利几乎恒正 → 覆盖率接近 100%；而 EV 在净现金公司会变负、EBIT 有 17.6% 为负。
2. **毛利反推不出 EBIT**：中间要减掉期间费用，而 margin 恰恰是最难预测的部分
   （Divo et al. arXiv:2411.05791：营业利润是最难预测的字段；BlackRock：价格会预测营收、**不会**预测利润率）。
3. 毛利的增量 IC（0.197）本来就高于 EBIT（0.118）。

⚠️ **未核实**：`毛利/市值` 这个具体估值变体的文献地位我没确认（本轮联网额度用尽）。
确证的是 **毛利/总资产（GP/A）** 是 Novy-Marx 的正式因子（raw 0.31%/月、FF3 alpha 0.52%/月），
且 Green–Hand–Zhang 从 94 个特征筛出的 12 个独立有效特征**不含任何水平估值比**，全是成长类。
"毛利/市值"机制上成立，但收益大概率主要来自估值那一半。

## 5. 窗口约定（**上一版写错过，务必保持**）

`j` = 锚点日 t 之前最后一个已结束的季度。**所有分母和基准都只用 ≤ j 的数据。**

```
label  y = 只用未来窗口   (j+1 .. j+h)
bench  b = 同一形状、紧邻其前的一个窗口   (j-h+1 .. j)
```

两个窗口**不重叠**，`b` 才是干净的对照。上一版的两个错误：

- 以 `j-3` 为基点、窗口取 `[j-3, j+h-4]` → **h>4 时会伸进未来季度（前视）**。
- 存量项直接用 `[j-3, j+h]` 当标签 → "已经实现的变化"占了标签的绝大部分，
  实测 `corr(y,b) = 0.993`，**标签几乎完全被预先决定，预测变得无意义**。

**自检**（`build_labels` 后手算核对）：对 `000001.SZ j=20` 三个头逐一核对过，
`y`、`b` 的期望值与实际值完全一致。

另一个副产品：`revenueGrowth` / `assetGrowth` 的 `corr(y, b) ≈ −0.0001`，
即**成长率近似随机游走、几乎没有持续性**（与 Ball & Watts 1972 一致）。
所以这两个头上，基准本身没有预测力 —— **模型在这两个头上拿到的 IC 全是增量的**，
这是对我们最有利的设定。只有 `grossProfit1` 的 `corr(y,b)=+0.385`（毛利率水平有持续性），
需要格外小心别把持续性算成能力。

## 6. 怎么用（三种用法都能落地）

1. **多因子打分直接选股**：`score = z(预测毛利/总资产) + z(预测营收增长) − z(预测资产增长)`
   （资产增长**取负** —— 投资异象；实测 capex 变化 IC −0.169、ICIR −4.16，符号一致且极稳）。
   这三条正好是文献里最站得住的三个相互独立的异象（Novy-Marx 毛利率 / Green–Hand–Zhang 成长 / Cooper 资产增长）。
2. **财务超预期代理**：用预测的**残差 `r`** 排序 = 预测基本面 surprise，对应 A 股 SUE / 业绩预告行情
   （中金用 XGBoost 预测下一季 ROE 变化方向胜率 >81%、IC 4%；A 股公告后漂移 11~13%/年）。
   这是**增量信号最该用的地方**。
3. **前瞻估值倍数**：`预测毛利/市值`（见 §4）。注意判据是"**对比今天的毛利/市值**"，
   不是对比随机 —— 因为分母那一半（当期便宜）是免费的。

三种用法都被 `--labels {level,resid}` 的并行跑覆盖：用法 1/3 吃 `y`，用法 2 吃 `r`。

## 8. 实验结果（2026-09-23，A 股臂，seed 1，7 epoch）

数据：`Z:/quant_data/nowcast`，156,517 个样本（SHZ 86,006 + SHH 70,511）；
`Store` 过滤后 156,362 行（三种标签口径共用同一批样本）。
训练 86,464 / 验证 36,965 / **测试 32,933**（one 的 889 只 held-out A 股）。
脚本：`train.py --labels {level,resid}`、`diag_incremental.py`。

### 8.1 level 版（模型直接预测水平）

| 头 | IC | ICIR |
|---|---|---|
| grossProfit1 / 3 / 7 | +0.325 / +0.340 / +0.342 | 5.10 / 5.83 / 5.76 |
| revenueGrowth1 / 3 / 7 | +0.027 / +0.130 / +0.247 | 0.35 / 1.69 / 3.22 |
| assetGrowth1 / 3 / 7 | +0.177 / +0.272 / +0.318 | 1.96 / 3.22 / 4.04 |
| 平均 | **+0.242** | **3.46** |

### 8.2 基准对照（同一批测试样本）

`IC(正交化)` = 逐截面把「模型 rank」对「基准 rank」回归取残差后与实际的 IC，
**这才是基准之外的净信息**。`train.py` 那个 `IC(模型−基准, 实际−基准)` 两边都含
`−基准` 项，基准本身 IC 高时（grossProfit 0.77~0.83）会被机械抬高，不能直接采信。

| 头 | IC(模型) | IC(基准) | IC(正交化) | ICIR(正交) | IC(混合) |
|---|---|---|---|---|---|
| grossProfit1 | +0.325 | +0.772 | +0.095 | 1.79 | +0.629 ↓ |
| grossProfit3 | +0.340 | +0.829 | +0.087 | 2.11 | +0.684 ↓ |
| grossProfit7 | +0.342 | +0.772 | +0.138 | 2.77 | +0.678 ↓ |
| revenueGrowth1 | +0.027 | −0.329 | +0.033 | 0.49 | −0.138 ↑ |
| revenueGrowth3 | +0.130 | −0.023 | +0.138 | 1.87 | +0.085 ↑ |
| revenueGrowth7 | +0.247 | +0.190 | +0.207 | 2.90 | +0.257 ↑ |
| assetGrowth1 | +0.177 | +0.098 | +0.165 | 2.11 | +0.181 ↑ |
| assetGrowth3 | +0.272 | +0.285 | +0.207 | 2.86 | +0.316 ↑ |
| assetGrowth7 | +0.318 | +0.296 | +0.250 | 3.30 | +0.355 ↑ |
| **平均** | +0.242 | +0.321 | **+0.147** | | +0.339 |

**三条结论**：

1. **增量信号是真的**：正交化后平均 +0.147，8/9 个头 ICIR 1.8~3.3。方向成立。
2. **但"水平预测"整体打不过免费基准**（0.242 vs 0.321）。且 **grossProfit 头混入模型反而更差**
   （0.63~0.68 vs 0.77~0.83）→ **若用法是"预测毛利/总资产水平 → 算毛利/市值排序"，
   直接用上一期财报比训练模型更好。**
3. **assetGrowth / revenueGrowth 混合后有提升**（assetGrowth7 0.355 vs 0.296）；
   **revenueGrowth1 基本没用**（IC 0.027、正交 0.033、ICIR 0.49）。

### 8.3 level vs resid（关键定案：**不改成 resid**）

resid 版直接预测「实际 − 基准」。把两版化成同一个「水平预测」后比 **正交化 IC**：

| 头 | level | resid |
|---|---|---|
| grossProfit1 / 3 / 7 | +0.095 / +0.087 / +0.138 | +0.057 / +0.082 / +0.137 |
| revenueGrowth1 / 3 / 7 | +0.033 / +0.138 / +0.207 | +0.003 / **−0.082** / **−0.018** |
| assetGrowth1 / 3 / 7 | +0.165 / +0.207 / +0.250 | +0.028 / +0.023 / +0.056 |
| **平均** | **+0.147** | **+0.032** |

**level 版在 9 个头里的 7 个上胜出、另 2 个打平，平均 0.147 vs 0.032 —— 压倒性。**
resid 版在 revenueGrowth 上甚至为负。

**原因**：残差目标的信噪比低得多（resid std 只有 level std 的一半左右，且本身不可预测），
Pearson 损失会归一化掉尺度，于是梯度被噪声主导；而训练在水平目标上，编码器能从
**持续性强、可预测**的那部分拿到强梯度，学到更好的表征，增量信息事后用正交化照样取得出来。

→ **结论：保持 level 标签不变，不要改成残差标签。**「超预期」信号在组合层面用
`模型 与 基准 正交化后的残差` 取即可，不需要新标签、也不需要多训一版。

### 8.4 落到用途

- **用法 2（财务超预期代理）成立**：正交化 IC 0.09~0.25、ICIR 1.8~3.3 —— 模型值钱的地方全在这里。
- **用法 1/3（估值排序）对头 1 不成立**：毛利水平排序请直接用滞后一期财报；
  模型的贡献只在 h=7（正交 0.138）。assetGrowth 的混合有小幅提升，但需要最优化权重
  （现在用的是朴素 50/50 z-blend，不是最优）。
- 附带发现：**`revenueGrowth1` 的基准 IC 是 −0.329（负的）** —— 去年同期增长率对今年增长率
  是反向的，这解释了这个头为什么整体最难。

### 8.5 本轮踩过的坑（都会让结果不可信，已修）

1. **标签灾难性离群值**：`revenueGrowth` std 810/129/5723（中位数 1.03），源头是分母极小
   （借壳/微利公司，营收 3,900 元量级）→ 比值爆到 2,010,408 倍。z-score 后第 4–6 个头几乎
   全是 0，**等于没在训练**。按项目既有口径截断 ±127（`three`/`seven` 同），std 降到 1.0~3.7，
   只影响 0.005~0.05% 样本。
2. **`Store` 没防 NaN**：21 行（0.013%）标签非有限 → 会让 `y_std` 变 NaN、整批标签跟着 NaN。
   已在 `Store` 统一过滤（只丢 155 行）。
3. **未解释的遗留**：这 21 行的成因是「去年同期营收之和为负」导致基准分母 ≤0，
   按 `ok` 定义生成时**本不该收录**；复算三遍没定位生成端为何放行
   （`y − b = r` 在 140 万个元素上完全精确，所以不是错位）。量级 0.013%，用 `Store` 兜住了，
   但**这是已知遗留、不是已解释**。
4. **`diag_incremental.py` 的量纲坑**：`train.py` 的 `predict()` 返回**标准化空间**输出。
   IC 是 rank 口径所以 level 模式无碍；但 resid 模式要做 `基准 + 增量` 的加法，
   必须先还原量纲（修完平均正交 IC 0.030 → 0.032，结论不变，但过程必须正确）。

## 9. 最终结论（2026-09-23）：三种标签设计全部在收益端失败

后续又测了两种标签设计（详见 `variants.py` 的 `v1`/`v5`/`u1`），**收益端结论一致**：

| 标签形式 | 模型 IC（889 只 held-out A 股） | 收益 vs 免费基线（h=1/3/7） |
|---|---|---|
| 毛利/总资产（level，本文 §3） | 0.34（但**免费基准 0.79**，灌水） | −1.56 / −2.98 / −7.95 |
| 毛利增长（比值，`v1`） | 0.13 | −0.30 / −1.03 / −2.36 |
| **u1 同比 delta（用户设计）** | **0.16~0.36，ICIR 1.9~3.7，9/9 全正** | **−1.25 / −3.10 / −7.10** |

**u1 是全程最干净的证据**：朴素预测是"不变"（=0，无截面变化）→ **没有免费持续性可以灌水**，
所以那些 IC 全是模型自己的贡献，样本外、三个头 × 三个期限**全部显著为正**。
**模型确实学会了预测毛利/营收/总资产的同比变化。**

**但收益端依然显著跑输**（t = −3.4~−5.1，胜率 15~29%），**且跑输全市场等权**。

### 根本原因：信息源，不是标签设计

输入只有 889 天价量，而**财务变化已被价格提前反映**。实测：同一个 `mom889`

| 预测对象 | IC | t |
|---|---|---|
| 「模型预测的毛利改善」 | **+0.45** | +25 |
| 「未来 1/3/7 季收益」 | **−0.10 / −0.14 / −0.17** | −5.6 / −8.7 / −13.3 |

**同一个信号，对财务量正向、对收益反向。** 这就是"业绩变好→股价上涨"这个直觉为什么不成立的答案：
**业绩变好的那一刻，股价早就涨完了**（价格领先盈利 1~8 个季度，FERC）。

模型学到的实质是**动量代理**：与 `mom889` 截面相关 **+0.46**；**剥离动量后增量归零**
（多空差 t 从 −5.46 掉到 **+0.07**）。

### 必须记住的方法论坑（这一轮踩出来的）

1. **财报披露前视**：锚点在季度末时"最后一个已结束的季度 j"**还没披露**（A 股 Q2 到 8/31、
   Q4 到次年 4/30）→ 用 `GP[j]` 就是偷看未来。**这曾让"免费基准 IC 0.79"虚高**，对模型不公平；
   修掉后基准约 0.6。**`u1` 用 `j-3` 做基准，天然避开了这个坑。**
   （量级：越依赖最新一季的信号受前视影响越大——估值信号保留 71%，毛利提升信号只剩 36~41%。）
2. **Spearman IC 对 balance 存量项会让「水平」和「变化」完全等价**（差一个常数 1）。
3. **A 股等权收益被极值主导**：全市场 1 季**原始均值 +161%**、中位数只有 **+1.47%**
   （停牌/重组复牌能让个别股票"收益"翻几十倍）→ **必须用中位数或 winsor 均值**。
4. **单因子筛选不可信**：它判"营收增长"没用（−0.047）而模型拿到 +0.138；判"营收/总资产" 0.142
   而模型只有 0.068 —— **两个方向都错**。
5. **判据阶梯**：loss → 标签 IC **vs 朴素基准** → 正交化 IC → 最优混合权重 →
   **分组收益 + 动量中性化**（终点）。前四层都可能被持续性/已知因子蒙过去。

### 唯一还没被否定的方向

**换信息源**。价量之外唯一经得起检验的是**财报本身**：
`毛利提升/市值`（IC +0.042，与动量只相关 +0.14）。它虽弱，但是独立信息。
→ 已用于生产估值公式的改进，见 `生产估值公式诊断与改进.md`。
