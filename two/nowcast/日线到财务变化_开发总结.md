# 从日线价量预测财务变化 —— 一条路是怎么趟出来的

> 一句话：**用 889 天日线（价量 + 31 个技术因子）预测公司未来 7 个季度的财务变化，模型做到了 IC ≈ 0.26~0.38（跑赢免费外推 +0.14），但在 A 股的收益端没有优势。**

这份文档记录的是**过程**：为什么这么想、每一步撞了什么墙、哪些做法被证伪。结论本身不复杂，值钱的是中间那些坑。

文档分两部分：

1. **一~四节（主线）**：从日线预测财务变化这条路，怎么设计标签、怎么验证、最后的可预测性与收益端结论。
2. **五节（延伸）**：既然"能预测但没收益"，就回头把生产链上**已有的**那个估值公式（`buffett`）诊断了一遍 —— 那里发现了**比模型本身更大的问题**（公式在给自己的主力因子做负贡献）。两个方向在"毛利提升"这个量上接上了。
3. **六~十节**：踩过的坑、被证伪的训练侧尝试、最终配方与上线、给接手人的建议。

---

## 一、思路：为什么不直接预测股价

起点是 Euclidean Technologies 那篇 *Improving Factor-Based Quantitative Investing by Forecasting Company Fundamentals* 的路子（业内叫 **nowcasting**）：**不预测收益，预测基本面**。

理由有三条：

1. **信噪比**：日线预测次日收益的 IC 上限大概 0.03~0.05；预测财务量的 IC 可以到 0.3 量级 —— 后者是**能被验证的信号**，前者大部分是噪声。
2. **可复核**：财务量后来真的会披露，模型猜得准不准可以逐条对账；"预测涨跌"永远说不清是模型不行还是运气不好。
3. **先为不可胜**：先把"能可靠预测"这件事拿下来（这是本金、是地基），能不能变现是**下游的、独立的**问题。反过来，一个预测不了的模型谈变现是空转。

所以目标定成：**输入日线 → 输出财务变化**。

## 二、数据与设定

| 项 | 设定 |
|---|---|
| 市场 | **31 个交易所**（A 股 SHZ/SHH + 全球 29 所），**47,078 只**股票，2000 年起 |
| 输入 | 锚点日往前 **889 个交易日**（= 127×7）× **31 维**：`open/high/low/close/volume/delta` + 24 个技术因子 + 时间索引 |
| 归一化 | 价格/成交量 ÷ 窗口最后一天的收盘价/成交量（所以是**尺度无关**的） |
| 测试集 | 从 31 所**按各所股票数等比例随机抽 889 只**（种子 42），**股票级严格隔离**（训练/验证/测试不共股票） |
| 训练/验证 | 其余股票随机 70/30（种子 12345） |
| 模型 | 与项目里其它模型同构的 Transformer 编码器（128 维、4 层、8 头），**1,028,486 参数**，输出 3 个头 |
| 训练 | Adam，lr 1e-3，7 轮，batch 64，损失 smooth_l1（标签先 z-score 再裁 ±8） |
| 单轮成本 | 约 **6,000 步 / epoch**（batch 64），**约 15 分钟/epoch**，7 轮约 2 小时 |

**锚点**：每只股票在满足"前后窗口都完整"的交易日上取一个样本。测试股用固定的 31 交易日网格（这样才能算逐日截面 IC），训练股按 1/31 概率随机抽。

## 三、走过的路：标签设计迭代

这是全程最花时间的部分。**同一份输入特征，只换标签的定义，看哪个最可预测。**

### 阶段 1：用"水平"当标签 → 被免费基准打趴

最初三个头是**水平量**：`毛利/总资产`、`营收增长`、`Δ总资产/总资产`（期限 1/3/7 季，共 9 个头）。

结果模型 IC 0.34，看起来不错 —— **但"朴素持续性基准"（用上一期财报直接当预测）IC 是 0.79，把模型打趴了**。

> **第一个坑（也是最重要的一个）**：财务量有极强的持续性，所以"预测水平"这件事本身很便宜。模型 IC 高≠有信息。**必须和同口径的免费基准比，比不过就是零。**

### 阶段 2：改用"变化"类标签 → 基准恒为 0，IC 才是真信息

把标签改成**变化**：`label = (未来窗口的值 − 过去窗口的值) / 分母`。这样"朴素预测 = 不变"对应 `b ≡ 0`，在排序上是零信息 —— **模型的 IC 就全是它自己的贡献**。

然后系统地扫这些自由度：

| 变体 | 分母 / 锚点 / 统计量 | 想法 |
|---|---|---|
| `u1` | `(ΣX_fwd − h·X[j−3]) / (h·X[j−3])` | 自相对同比，天然消季节 |
| `u2` | 分子 `/ 市值` | 分母恒正且大 |
| `u3` | 分子 `/ 总资产[j−3]` | 恒正稳定、不带价格 |
| `u4` | 用「最后**已结束**季度 jc」 | 最新鲜，但失去季节对齐 |
| `u5` | 锚点**所在**季 | 折中 |
| **`u6`** | **`(median(X[jc+1..jc+7]) − median(X[jc−6..jc])) / 总资产[jc]`** | **中位数抗单季异常 + 7 季长窗口** |
| `u7` | u6 的 h=1/3/7 版 | 检验期限 |
| `u8` | 每季先做同比差分、再取中位数 | 把季节对齐和中位数合并 |

### 阶段 3：干净对照（7 轮、同配置、修完 bug 后）

| 变体 | 头数 | 验证 IC（最佳）| 整体 IC | A股 IC |
|---|---|---|---|---|
| **u6** | 3 | **0.3650** | **+0.3343** | **+0.2896** |
| u3 | 9 | 0.3355 | +0.3150 | +0.2673 |
| u7 | 9 | 0.2688 | +0.2489 | +0.2052 |
| u8 | 3 | 0.2356 | +0.2269 | +0.1927 |

**u6 四项全胜。** 三个头各自的成绩（测试集）：

| 头 | 整体 IC | A股 IC | **逐日 IC** | 逐日 ICIR |
|---|---|---|---|---|
| `gpMed7`（毛利）| +0.2762 | +0.2647 | **+0.2609** | 2.52 |
| `revMed7`（营收）| +0.3137 | +0.2679 | **+0.2847** | 2.89 |
| `taMed7`（总资产）| +0.4128 | +0.3361 | **+0.3756** | 2.97 |
| **平均** | **+0.3343** | **+0.2896** | | |

> 注意：**整数（pooled）IC 会灌水**，跨日期的水平差异会抬它。诚实口径是**逐日截面 IC**（每天在截面内算一次秩相关，再对日期平均）。

### 阶段 4：它到底比"免费"好多少？（这才是成败判据）

`u6` 的朴素基准恒为 0，所以真正的对照是**"上一轮 7 季的变化重演"** —— 完全免费、不用任何模型：

| 评分 | 逐日 IC | ICIR |
|---|---|---|
| **模型（毛利头）** | **+0.2615** | 1.70 |
| 免费基准：上一轮 7 季变化重演 | +0.1197 | 0.65 |
| **超出** | **+0.1418** | |
| 两者秩相关 | **+0.232** | |

**模型比免费外推高出 +0.14，且两者相关只有 0.23** —— 它不是单纯在说"上一轮怎么变、这一轮还怎么变"。

再看分位单调性（按模型预测分 10 组，看各组**实际**发生的财务变化，单位 = 占总资产 %）：

| 预测分组 | 全体 | A股 |
|---|---|---|
| 1（最不看好）| −0.068% | −0.065% |
| 5 | +0.217% | +0.268% |
| 10（最看好）| **+1.443%** | **+1.421%** |
| **单调性** | **9/9 步** | **8/9 步** |
| **最高−最低** | **+1.511%** | **+1.487%** |

标签本身的 IQR 只有 **1.689% 占总资产** —— 也就是说**模型挑出的最高组和最低组之间的实际差距，约等于整个分布中间一半的宽度**。这不是"轻微倾斜排序"，是真的把分布分开了。

## 四、收益端：诚实的结论 —— A 股没有优势

预测财务变化 ≠ 赚钱。把模型输出换算成"预测的未来毛利 ÷ 市值"当评分，和免费的价值因子（过去 7 季毛利中位数 ÷ 市值）比：

| 持有 | 模型 IC | 免费基线 IC | **超出** | A股超出 |
|---|---|---|---|---|
| 1 季 | +0.0345 | +0.0358 | −0.0013 | −0.0010 |
| 3 季 | +0.0333 | +0.0366 | −0.0033 | −0.0044 |
| **7 季**（标签对齐期）| +0.0623 | +0.0719 | **−0.0095** | −0.0127 |

**三个持有期全部为负**，组合层也一样（7 季前 50% 中位数收益：模型 13.41% vs 基线 13.74% vs 全市场 10.63%）。

我们还试了一条**有文献依据**的路：资产增长（`ta` 头）在学术上是**负向**收益因子（Cooper–Gulen–Schill 资产增长异象），所以把 `ta` 头的预测**取负号**用。结果：

- **全体样本**：剥离动量后仍有 +0.054（ICIR 0.44），而免费的"−上一轮资产变化"只剩 +0.014 → **模型在全球样本上有独立信息**
- **A 股**：模型 +0.025 **反而输给**免费版 +0.047 → **优势消失**

> **结论**：这条路的产出是**一个可靠的基本面预测器**，不是一个 A 股交易信号。想变现得换信息源（价量之外的东西），或者用在一开始就避开"价格已定价"这个问题的环节。

## 五、延伸：顺手把生产链上已有的估值公式也诊断了

既然"模型能预测但没收益"，注意力就转向**生产链上已经存在的那个估值环节** —— 它只用财报 + 价格，完全不依赖模型。

### 现状公式

```
zero 模型过滤（zero > 中位数，避雷）
    ↓
buffett = dcf × (每股净资产 / 收盘价) +  schloss
          ↑ seven 模型输出    ↑ B/P        ↑ 营运资本/股价（格雷厄姆）
    ↓
按 buffett 分档（全量/127/31/7/3）→ 档内按 up_down 取第一名
```

### 发现 1：乘法是对的，加法错了

```
dcf × B/P = (预测Σ自由现金流 / 净资产) × (净资产 / 市值)   ← 净资产约掉
          = 预测自由现金流 / 市值
```

**这正是 LFM 的标准构造**（预测未来基本面 ÷ 当前市值 = 前瞻收益率）。所以"用预测现金流算前瞻估值倍数"**思路没问题**。

### 发现 2：加法被 `schloss` 淹没了

| 项 | 中位数 | IQR 宽度 |
|---|---|---|
| `dcf × B/P`（预测 FCF/市值）| +0.006 | 0.064 |
| `schloss`（营运资本/市值）| **+0.066** | **0.238** |

schloss 的 IQR 是另一项的 **3.7 倍**，于是：

```
corr(buffett, schloss)    = +0.937     ← 几乎完全等同
corr(buffett, dcf × B/P)  = +0.296     ← 几乎无关
```

**生产的 `buffett` 实质上就是一个 schloss 排序** —— 而 schloss 自己的 IC 只有 +0.025。

### 发现 3：`dcf` 当**乘数**会削弱主力因子

| 因子 | IC vs 未来 1 季收益 |
|---|---|
| **`B/P` 单独** | **+0.0806** |
| `dcf × B/P` | **+0.0220** ← 掉 73% |
| `dcf` 单独 | +0.0163 |

用一个 IC≈0.016（≈噪声）的因子去**缩放**一个 IC 0.081 的强因子 = **注入噪声**。

（顺带：seven 预测未来 FCF 很准，`ic_fcf_combined` = **0.593**；但 FCF/市值 预测收益只有 **0.022**。**"预测得准"和"预测值有区分度"是两件事** —— FCF 这个量已经被市值定价了。）

### 发现 4：A 股里"什么口径的便宜"才有效

| "便宜"的口径 | 分子来源 | IC vs 未来 1 季收益 |
|---|---|---|
| **B/P**（账面市值比）| 资产负债表 | **+0.081** |
| **毛利/市值** | 利润表**顶部** | **+0.075** |
| 毛利提升/市值 | 利润表（同比变化）| +0.042 |
| 营运资本/市值（schloss）| 资产负债表 | +0.025 |
| 自由现金流/市值 | 现金流表 | +0.022 |
| EBIT/EV | 利润表**中部** | ≈ +0.01 |

> **规律：越靠利润表"上方"的科目越有效（毛利 ≫ EBIT ≈ 净利），现金流类几乎无效。**

所以 **LFM 原版的 `预测EBIT/EV` 在我们的数据上不成立**：免费的"上一期 EBIT/EV"多空 t 只有 1.89 / 0.60 / −0.10，而把模型的 EBIT 预测加进去是**反向**的（Q1−Q5 = −1.03 / −5.01 / −14.84）。

### 发现 5：`schloss` 是"降波动项"不是"alpha 项"

λ 扫描 `score = z(B/P) + λ·z(schloss)`（多空夏普随 λ 单调升到 1.23），**但多头组最优在 λ≈0.25~0.5**：

| λ | 多空夏普 | 前 50% 收益 |
|---|---|---|
| 0.00（去掉）| +0.97 | +2.61% |
| **0.25** | +1.05 | **+2.65%** |
| 0.50 | +1.18 | +2.64% |
| 2.00 | **+1.23** | +2.19% |

**生产是纯多头**，多空夏普的提升对他没价值。从量级推断生产里 schloss 的等效权重 λ≈2 → **过度加权 4~8 倍**。

### 发现 6：合成方案对比（h=1，同一批样本）

| 方案 | Q1−Q5 | 多空 t | 前 50% 收益 | 前 50% 夏普 |
|---|---|---|---|---|
| **A 现状**：dcf×B/P + schloss | +0.94% | +2.21 | +1.88% | 0.62 |
| B 同样三项，改「标准化后相加」| +3.09% | +5.90 | +2.33% | — |
| **D 只用 B/P** | **+4.04%** | +4.24 | +2.53% | — |
| 现状 + 毛利 + 毛利提升 | +3.64% | **+7.36** | +2.96% | **0.74** |
| 去掉 dcf + 毛利 + 提升 | **+4.20%** | +6.43 | **+3.04%** | 0.73 |

两行最值得看：

- **D 那行：只用 B/P 就比整套公式好 4 倍** → 现在的公式在给自己的主力因子做**负贡献**
- **A → B 只是改了形式（一个因子都不动）就把 Q1−Q5 提了 3.3 倍** → 合成方式比因子选择更重要

### 当时建议的新公式（待讨论）

```python
buffett = z(B/P)            # 主力，IC 0.081（四个口径里最强）
        + z(毛利/市值)       # 新增，IC 0.075（第二强）
        + z(毛利提升)        # 新增，价量外的独立信息（与动量只相关 +0.14）
        + 0.25·z(schloss)   # 降波动项，小权重
        # dcf 去掉（IC≈0.02，且当乘数会削弱 B/P）
```

预期：前 50% 收益 **1.88% → 3.04%**、年化夏普 **0.62 → 0.73**、多空 t **2.21 → 6.43**。

**三个要点**：① **必须 rank 标准化后再合成**（否则 schloss 会再次淹没一切 —— 零成本、收益最大的改动）；② `dcf` 从"乘数"改成独立加项或去掉；③ 加「毛利/市值」和「毛利提升」。

### 与本文档的关系

新公式里建议增加的「**毛利提升**」（IC +0.042）是**唯一经得起检验的价量外信息源** —— 它测的是**已经发生**的毛利改善。
而本文档前面训练的模型，产出的正是**同一个量的前瞻预测**（`gpMed7`）。**这两条线在这里接上了。**

### 未完成项与限制（读结论时要记住）

- `dcf` 用的是**代理**（近 4 季实际现金流），不是 seven 的历史真实输出 —— 要正式定案得让 seven 产出历史 dcf
- `write_stock_data.py` 里有 `dcfPerShare` 列，公式没用它 —— 口径值得核一下
- `zero > 中位数` 那道前置过滤的效果**从没测过**（它砍掉一半候选）
- 全是**毛收益**：等权、无交易成本、无 ST/流动性过滤、无涨跌停限制
- 夏普只用 **h=1**（锚点间隔 = 持有期，非重叠，干净）；h=3/7 重叠，夏普偏乐观
- **没做横截面聚类稳健标准误** —— 同一季度 8000 只股票共享市场因子，**t 值偏乐观**
- 试了七八个方案，**多重检验**风险；但"改形式大幅改善"不依赖挑参数，较稳
- 回测锚点在**季度末**，生产跑在任意日 → 生产能用到更新的财报，所以**回测比生产更保守**

## 六、踩过的坑（最有价值的部分）

### 坑 1：朴素持续性基准（前面说过）

财务量有强持续性 → "预测水平"很便宜。**任何"预测财务"的项目，第一件事是找出免费基准并同口径比。**

### 坑 2：asof 在"过滤后的行集"上算 → 凭空造出"已经实现"的未来标签

这是最凶的一个，**污染了整个标签家族**。

为了"让样本行和生成端一致"，标签脚本里先做了一个过滤：
```python
lab = lab[lab.ok]          # ok 要求「未来 7 季完整」
lab['avail'] = available_date(lab.j_endDate)   # ← 然后在【缩小后的行集】上算披露日
```
后果：**每只股票最后 7 个季度被滤掉了** → 锚点落在最近期时，找"最后一个已披露季度"就**退回更早的季度** → 于是

- 本该没有标签的最近期锚点被**凭空造出**标签
- 造出来的标签，其"未来窗口"有一大截落在锚点日**之前**（**已经发生的事**）→ 模型当然好预测 → **系统性抬高 IC**

实测：**这类行占 10.61%**（越靠后的分块越严重，最末一块掉了 78%）。
修完的对比：`u3` 的验证 IC **0.3519 → 0.3355**（虚高 +0.016）；而 `u6` 反而是 0.3475 → 0.3650（**方向相反**）。

> **教训**：① 「样本行对齐」这种看起来无害的一致性处理，会悄悄改变语义；② "污染 ⇒ IC 一律虚高"是错的，但"污染 ⇒ 数字之间不可比"是对的；③ **修完必须重跑，别拿旧数字当基准。**

### 坑 3：泄漏自检不能用日历推算

判断"标签的未来窗口有没有落在锚点日之前"，如果用**日历推算的季度末**（jc + h 个季度）去比，非 A 股市场的财报不严格按季度、面板有跳档 → **大量误报**（XETRA 误报 2,120 个）。正确做法是用**面板的实际行**（`endDate[行号 jc+h] <= 锚点日`）。

### 坑 4：验证 IC 的改进不传导到测试集

给训练加了"余弦退火学习率 + EMA 权重平均"，**验证 IC 连续 7/7 轮都比基线高**。但配对检验（同一批测试行、逐日 IC 配对 t）显示：

- 毛利头 **−0.0081（t = −2.52，显著变差）**
- 总资产头 **+0.0099（t = +3.04，显著变好）**
- 三个头平均：打平；A 股：略差

**是"重新分配"，不是"改进"。** 原因很可能是我们整套流程都用验证 IC 选 checkpoint —— **验证集本身是被"选中"的**，所以它上面的改进不一定泛化。**测试集才是诚实的裁判。**

（这条也解释了一个反直觉现象：一个改动可以让验证指标稳定变好，却不产生任何真实增益。）

### 坑 5：分母必须是"稳定的锚"，不能是"每季重算的噪声源"

`u8` 的设计是"每季先做同比差分、再取中位数"（每个分量是 `X_q/TA_q − X_{q−4}/TA_{q−4}`）。它把**每季的总资产**放进了分母，而 TA 自己有噪声、差分又放大一次 → **每个分量两次噪声放大**。

实测：同一个单季冲击下，`u6` 和 `u8` 的**绝对抖动一样大**（0.00045 vs 0.00044），但 `u8` 的信号尺度只有 `u6` 的 **0.567 倍**（≈ 4/7）→ 信噪比差 1.75 倍。后果是**毛利/营收头腰斩 58%**，而**总资产头只跌 11%**（它没有"除以噪声源"这一步）。

> **设计原则：分母用一次、用一个稳定的量（`总资产[jc]`）；不要每季重算。**

### 坑 6：期限的作用取决于"有没有同比对齐"

| 逐日 IC | h=1 | h=3 | h=7 |
|---|---|---|---|
| `u7`（无同比对齐）| gp **0.048** / rev 0.074 | 0.157 / 0.193 | 0.256 / 0.282 |
| `u3`（**有**同比基准 j−3）| 0.246 / 0.253 | 0.239 / 0.255 | 0.252 / 0.279 |

- 没有同比对齐时，**短期限直接崩掉**（一个季度的水平差被季节效应和单季噪声吞没）
- 有同比对齐时，**各期限几乎一样好**

**规律：短期限靠同比对齐，长期限靠中位数平滑。** `u6` 只做了后者（所以它只有 h=7 好用，但 h=7 最强）。

## 七、训练侧也试过（都是负结果）

| 尝试 | 结果 |
|---|---|
| **pearson 损失**（直接优化"同日截面相关"= 评估指标）| 但变长同日 batch 要跨大量文件随机读，**训练慢一倍**；且在旧数据上 pre-训练轮就低于基线；干净版跑到一半**卡死在显存耗尽** → 放弃 |
| **余弦退火 + EMA** | 见坑 4：验证好、测试打平 → 不采纳 |
| **多种子权重平均** | 未做（刻意保留模型自身的随机性）|
| 改模型规模 / 加长周期动量因子 | 未做（刻意与项目原有模型保持一致，保证可比）|

> **一个总经验**：换过 9 种标签设计 + 2 种训练侧改动，三个头的 IC 全落在 **0.25~0.38** 这个带里，**没有一次跳出量级**。这说明**约束在信息源（只有价量），不在损失函数、不在标签形式更细的雕琢上。**

## 八、最终配方与复现

```
标签   u6：label = ( median(X[jc+1..jc+7]) − median(X[jc−6..jc]) ) / 总资产[jc]
       三个头 = 毛利 / 营收 / 总资产（各 1 个值）
       jc = 锚点日前【最后一个已结束】的季度
损失   smooth_l1（逐样本，标签 z-score 后裁 ±8）
优化器 Adam，lr = 1e-3 恒定（不加调度、不加 EMA）
轮数   7    种子 1    验证划分种子 12345
模型   Nowcast(3 字段 × 1 期限)，1,028,486 参数
```

```bash
python two/nowcast/train.py --arm both --suffix u6 --labels level \
  --test-mode global_random --test-n 889 --test-seed 42 \
  --seed 1 --epochs 7 --val-seed 12345 \
  --root <数据目录> --tag _u6
```

**代码位置**：`nowcast/`
- `labels.py` / `variants.py` —— 标签定义（单一事实来源）
- `add_u6_labels.py` —— u6/u7/u8 的标签生成（`--form meddiff|yoymed`）
- `gen_data2.py` —— 特征生成 + **`build_x()`**（训练与推理共用同一段特征代码，关键）
- `train.py` —— 训练 + 评估
- `eval_v2.py` —— **收益端**评估

## 九、上线

这个模型已经**取代了每日预测链里的 `two` 阶段**：

```
seven → three → zero → schloss → two → one → buy_predict.csv
```

- `two` 只取**毛利头**的输出，用它把候选池**砍掉后一半**（砍半的动作在 `one` 里，一行中位数过滤）
- 特征一致性做了**逐元素验证**：从存档训练数据取 45 个 `(股票, 锚点)`，用推理路径重算 → **1017×31 完全一致**（这一步抓出了 3 个隐蔽的坑：日线过滤条件、索引未重置、以及"输入窗口 1017 行但模型只吃前 889 行"）
- 顺带修了一个既有 bug：`one` 的推理脚本**没调 `model.eval()`**，而模型是训练模式存的 → **dropout 在推理时一直开着**，同一输入 4 次前向的输出极差 **7.34** → 每天的最终选票带随机漂移。加一行 `.eval()` 修好。

## 十、给接手人的五句话

1. **判据要分层**：先看"标签预测得多准"（IC / 分位单调性），再看"比免费基准好多少"，最后才看"能不能赚钱"。**这三层经常给出相反的结论，混着看必错。**
2. **任何标签（或特征）改动，先跑一个"是否泄漏 / 是否与免费基准同口径"的检查**，再谈训练。我们最难查的那个 bug，就是靠"独立重算 + 逐元素比对"抓出来的。
3. **这条路的产出是"可预测性"，不是"收益"。** 在这个信息源（纯价量）下，A 股的收益端是堵死的 —— 想要收益，得换信息源，而不是继续雕琢标签。
4. **"预测得准"和"预测值有区分度"是两件事**：seven 预测 FCF 的 IC 有 0.59，但 FCF/市值 预测收益只有 0.022 —— **一个被模型预测得很准的量，可能已经被市场定价完了**。反过来，那个把 B/P 从 0.081 削弱到 0.022 的操作，本质是**用噪声因子去缩放了强因子**。
5. **合成形式常常比因子选择更重要**：生产公式只把"相加"改成"先标准化再相加"（一个因子都不动），Q1−Q5 就从 +0.94% 提到 +3.09%。**先检查权重和量级，再去换因子。**
