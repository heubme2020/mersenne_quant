## 0. 起因

`nowcast` 这条线的最终结论是：**日线模型能预测财务变化，但没有经济价值**（详见第 4 节）。
于是把注意力转向**生产链路上那个已经存在的估值环节**——它只用财报 + 价格，不依赖模型。

用户原话：「我们系统还有估值这个环节，现在用的是 schloss + buffett，其实可以考虑优化的」。

## 1. 生产流程与公式

`refresh_candidates.py` 的最终选票逻辑：

```
zero 模型过滤（zero > 中位数，避雷）        ← LFM 说的"识别价值陷阱"，做得对
    ↓
buffett = dcf × (每股净资产/收盘价) + schloss
          ↑seven输出   ↑ B/P              ↑ 营运资本/股价（格雷厄姆）
    ↓
按 buffett 取前 N（1/127/31/7/3）→ 再按 up_down（one/two 的价格预测）取第一
```

**`buffett` 定义在 `two/get_two_predict.py:205`**；成分来源：
- `dcf`：`seven/get_seven_predict.py:287-297` —— **只用 fcf 分支**，3/7/31 季预测之和
  （seven 的 fcf 标签 = `Σ自由现金流[j+1..j+h] / 净资产[j]`）
- `schloss`：`schloss/get_schloss.py` —— `operatingCapitalPerShare / close`，限 0/3/6 开头
- `B/P`：`netAssetValuePerShare / close`，来自 `indicator_*.csv`

**前置过滤**：`zero_predict.csv` 的 `zero > median`（只要一半），然后与 schloss 内连接。

## 2. 结论：`dcf × B/P` 的数学是对的，错在两处

### 先纠正一个误解：这个乘法本身没问题

```
dcf × B/P = (预测Σ自由现金流 / 净资产) × (净资产 / 市值)
                                        ↑ 净资产约掉了
          = 预测自由现金流 / 市值
```

**这就是 LFM 的标准构造**（预测未来基本面 ÷ 当前市值 = 前瞻收益率）。
所以「用预测的现金流去算前瞻估值倍数」**思路是对的**，不是设计错误。

### 错误 1：加法被 `schloss` 淹没（dcf 与 B/P 名义存在、实际缺席）

两项的截面量级：

| 项 | 中位数 | IQR 宽度 |
|---|---|---|
| `dcf × B/P` = 预测FCF/市值 | **+0.006** | 0.064 |
| `schloss` = 营运资本/市值 | **+0.066** | 0.238 |

schloss 的 IQR 是另一项的 **3.7 倍**、中位数 **11 倍**。结果：

```
corr(buffett, schloss)      = +0.937   ← 几乎完全等同
corr(buffett, dcf × B/P)    = +0.296   ← 几乎无关
```

**→ 生产的 `buffett` 实质上就是一个 schloss 排序。** 而 schloss 单独的 IC 只有 +0.0245（见第 3 节）。

### 错误 2：`dcf` 当**乘数**会削弱主力因子

| 因子 | IC vs 未来 1 季收益 |
|---|---|
| **`B/P` 单独** | **+0.0806** |
| `dcf × B/P` | **+0.0220** |
| `dcf` 单独 | +0.0163 |

**乘上 dcf 把 B/P 从 0.081 削弱到 0.022（掉 73%）。**
原因：dcf 自身对收益的 IC 只有 +0.016（≈噪声），用一个噪声因子去缩放一个强因子 = **注入噪声**。

### 为什么"seven 预测 FCF 很准"不顶用

| | 指标 | 结果 |
|---|---|---|
| seven 预测**未来自由现金流**（它的任务） | `ic_fcf_combined` | ✅ **0.593** |
| **FCF/市值** 预测**未来收益** | IC | ❌ **0.022** |

**FCF 这个量的"收益率"在 A 股没有区分度**——市值已经把 FCF 定价了。
而 B/P、毛利/市值有效，是因为市场对「账面价值」和「盈利能力」的定价有系统性偏差，对 FCF 没有（或已被套利）。

## 3. 成分体检（lag-safe，全 A 股 70 万观测 / 85 个季度截面）

### 3.1 各成分单独

| 方案 | h=1 Q1−Q5 (t) | h=3 | h=7 | 前50%（h=1/3/7） |
|---|---|---|---|---|
| **schloss** | +0.80 (+1.69) | +1.83 (+1.83) | +5.92 (+3.72) | +1.91 / +8.82 / +25.15 |
| **B/P** | **+4.23 (+4.48)** | **+8.10 (+6.47)** | **+15.29 (+6.92)** | +2.61 / +9.95 / +26.45 |
| dcf_proxy | 弱 | 弱 | 弱 | — |
| 毛利/市值 | +3.25 (+5.88) | +5.57 (+6.73) | +10.44 (+4.89) | +2.46 / +9.63 / +25.40 |
| 毛利提升/市值 | +1.63 (+5.56) | +2.22 (+4.00) | +1.04 (+1.11) | +2.18 / +8.86 / +23.10 |

（市场等权：+2.28 / +9.86 / +22.93）

**`schloss` 在短中期不显著（t=1.69/1.83）、五分组非单调、前 50% 跑输市场**；`B/P` 才是主力。

### 3.2 schloss 归因（λ 扫描，h=1 非重叠）

`score = z(B/P) + λ·z(schloss)`，`corr(B/P, schloss) = +0.180`（分散性尚可）

| λ | Q1−Q5 | 多空 t | **多空夏普** | 前50% 收益 | **前50% 夏普** |
|---|---|---|---|---|---|
| **0.00**（去掉） | **+4.20%** | +4.46 | +0.97 | **+2.61%** | 0.65 |
| **0.25** | +4.16% | +4.79 | +1.05 | **+2.65%** | **0.66** |
| 0.50 | +3.99% | +5.42 | +1.18 | +2.64% | **0.66** |
| 1.00 | +3.50% | +5.56 | +1.21 | +2.53% | 0.65 |
| 2.00 | +2.80% | +5.63 | **+1.23** | +2.19% | 0.63 |

**`schloss` 是"降波动项"不是"alpha 项"**：多空夏普随 λ 单调升到 1.23，
但**多头组**最优在 λ≈0.25~0.5。**生产是纯多头，多空夏普的提升对他没价值。**
从量级推断，生产里 schloss 的实际权重等效 λ≈2 → **过度加权 4~8 倍**。

### 3.3 合成方案对比（h=1，同一批样本）

| 方案 | Q1−Q5 | 多空 t | 前50% | 前50% 夏普 |
|---|---|---|---|---|
| **A 现状：dcf×B/P + schloss** | **+0.94%** | +2.21 | **+1.88%** | 0.62 |
| B 同三项改「标准化后相加」 | +3.09% | +5.90 | +2.33% | — |
| C 去掉 dcf | +3.47% | +5.30 | +2.42% | — |
| D 只用 B/P | **+4.04%** | +4.24 | **+2.53%** | — |
| **现状 + 毛利 + 毛利提升** | **+3.64%** | **+7.36** | **+2.96%** | **0.74** |
| 全标准化（+毛利+提升） | +4.03% | +6.65 | +2.99% | 0.73 |
| **去掉 dcf + 毛利 + 提升** | **+4.20%** | +6.43 | **+3.04%** | 0.73 |

**注意 D 那行**：**只用 B/P 就比整套公式好 4 倍** → 现在的公式在给自己的主力因子做负贡献。
而 **A → B 只是改了形式（不动任何因子）就把 Q1−Q5 从 0.94% 提到 3.09%（3.3 倍）。**

## 4. A 股「什么口径的便宜」有效

| "便宜"的口径 | 分子来源 | IC vs 未来 1 季收益 |
|---|---|---|
| **B/P**（账面市值比） | 资产负债表 | **+0.081** |
| **毛利/市值** | 利润表**顶部** | **+0.075** |
| 毛利提升/市值 | 利润表（同比变化） | +0.042 |
| 营运资本/市值（schloss） | 资产负债表 | +0.025 |
| 自由现金流/市值 | 现金流表 | +0.022 |
| **EBIT/EV** | 利润表**中部** | **≈ +0.01** |
| 预测FCF/净资产（dcf） | 现金流表 | +0.016 |

**规律：越靠利润表"上方"的科目越有效（毛利 ≫ EBIT ≈ 净利），现金流类几乎无效。**
与 Divo et al. (arXiv:2411.05791) 一致——**营业利润是最难预测、最没区分度的字段**。

**LFM 的原版构造 `预测EBIT/EV` 也测了，在我们数据上不成立**：
免费的"上一期EBIT/EV"t 只有 **1.89 / 0.60 / −0.10**（几乎无 alpha），
而模型的 EBIT 预测加进去是**反向的**（Q1−Q5 = −1.03 / −5.01 / −14.84）。

## 5. 建议的新公式（待讨论后实施）

```python
# 现状 —— Q1−Q5 +0.94%，前50% +1.88%，年化夏普 0.62
buffett = dcf × B/P + schloss

# 建议
buffett = z(B/P)            # 主力，IC 0.081 ← 四个口径里最强
        + z(毛利/市值)       # 新增，IC 0.075 ← 第二强
        + z(毛利提升)        # 新增，价量外的独立信息，与动量只相关 +0.14
        + 0.25·z(schloss)   # 降波动项，小权重
        # dcf 去掉（IC≈0.02，且当乘数会削弱 B/P）
```

**预期改善（h=1，全 A 股）**：
前50% 收益 **1.88% → 3.04%**、年化夏普 **0.62 → 0.73**、多空 t **2.21 → 6.43**。

**三个要点**：
1. **必须 rank 标准化后再合成** —— 否则 schloss 会再次淹没一切（这是零成本的改动，收益最大）
2. **`dcf` 从"乘数"改成"独立加项"或去掉** —— 它不该去缩放 B/P
3. **加「毛利/市值」和「毛利提升」** —— 尤其后者是**唯一经得起检验的价量外信息源**

## 7. 限制（读结论时要记住）

- 全是**毛收益**：等权、无交易成本、无 ST/流动性过滤、无涨跌停限制
- 夏普用 **h=1**（锚点间隔 63 天 = 持有期，**非重叠**，干净）；h=3/7 重叠，夏普偏乐观
- **横截面聚类稳健标准误没做** —— 同一季度里 8000 只股票共享市场因子，`t` 值**偏乐观**
- **多重检验**：试了七八个方案，单个结果有过拟合风险；但"改形式大幅改善"不依赖挑参数，较稳
- 回测的锚点在**季度末**，而生产运行在任意日 —— 生产能用到更新的财报（合法），
  所以回测比生产**更保守**；若要对齐，锚点应设在披露截止日之后
